# Trailer source footage

Place two real recordings in this directory before running **Actions → Build Persian Gameplay Trailer**:

- `gameplay.mp4`: captured footage of the actual خیزش فرمانروایان game.
- `player-camera.mp4`: a face-camera recording of the person playing the game.

The workflow overlays the player camera on the gameplay and adds Persian narration using a Persian neural voice. No synthetic gameplay or fake player footage is substituted for the real game. The resulting MP4 is uploaded as a workflow artifact.

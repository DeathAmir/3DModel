# AI Cinematic Trailer

This workflow generates a real 15-second text-to-video MP4. It does not create still images, slideshows, or fake gameplay footage.

## Model

- Model: Alibaba Wan 2.7 Text-to-Video, hosted by Replicate
- Duration: 15 seconds
- Resolution: 1080p
- Aspect ratio: 16:9
- Audio: generated by the video model (cinematic ambience and environmental sound)
- Prompt language: English
- Output: `outputs/trailer/kheezesh-farmanravaan-trailer-en.mp4`

The GitHub Actions runner only submits the request and downloads the result. Video inference runs on Replicate's hosted infrastructure, not on the GitHub runner CPU.

## One-time setup

1. Create an account at https://replicate.com/.
2. Create an API token at https://replicate.com/account/api-tokens.
3. Open this repository's **Settings → Secrets and variables → Actions**.
4. Add a repository secret named `REPLICATE_API_TOKEN` with that token.

The workflow cannot generate a video until this secret is configured.

## Run

Open **Actions → Generate 15s AI Cinematic Trailer → Run workflow**. Optionally provide a custom English prompt. When the job finishes, download the MP4 from the workflow run's **Artifacts** section.

A 15-second generation at the listed model rate of $0.10 per output second is approximately **$1.50 per run**, before any applicable taxes or account-specific charges. Check the model's current pricing before running.

## Notes

Wan 2.7 supports text-to-video clips from 2 to 15 seconds and can generate matching audio when no audio file is supplied. Longer clips can have some visual drift, so review the result before publishing.
